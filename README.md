# Dashboad-de-vendas-XBOX
### Desenvolvi um dashboard interativo no Excel focado na análise de vendas e assinaturas do Xbox Game Pass. O projeto organiza bases de dados, utiliza tabelas dinâmicas e fórmulas avançadas para responder perguntas de negócio de forma visual e intuitiva

## Estrutura da Planilha
O arquivo é organizado em quatro abas principais que separam a identidade visual, os dados brutos, os cálculos analíticos e o painel executivo:

Assets:
Centraliza a paleta de cores oficial do projeto (tons de verde Xbox, cores de menus e áreas neutras), além dos logotipos e ícones utilizados na interface visual.

Bases:
Contém a base de dados completa dos assinantes, registrando informações como ID do assinante, nome, plano contratado (Core, Standard, Ultimate), data de início, status de renovação automática, tipo de assinatura (mensal, trimestral, anual), pacotes adicionais (EA Play e Minecraft Season Pass), descontos aplicados e o valor total da venda.

Cálculos:
Área dedicada ao tratamento e cruzamento de dados por meio de Tabelas Dinâmicas e fórmulas para responder às principais perguntas de negócio, incluindo:
Faturamento total de planos anuais com assinaturas agregadas.
Receita de planos anuais segmentada por status de renovação automática (Sim ou Não).
Volume e faturamento total de assinaturas adicionais do EA Play por tipo de plano.
Volume e faturamento total de pacotes adicionais do Minecraft Season Pass.

Dashboard:
Painel visual interativo que consolida os principais indicadores de desempenho (KPIs), gráficos de receitas e segmentações dinâmicas para acompanhamento rápido das vendas.

Principais Recursos Técnicos
Tabelas Dinâmicas: Utilizadas na aba de cálculos para agrupar, filtrar e sintetizar grandes volumes de registros de forma ágil.

Design e Identidade Visual: Aplicação de paleta de cores padronizada, a expressão visual clara e elementos gráficos organizados para facilitar a leitura dos indicadores.
